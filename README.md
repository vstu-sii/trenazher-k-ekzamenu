# Тренажёр к экзамену

Проект команды курса «Системы искусственного интеллекта», ВолгГТУ.

## Что это

Студент второго курса за неделю до экзамена не знает, чего он не знает.
Тренажёр берёт его конспект, генерирует задачи по темам и объясняет
ошибку словами преподавателя.

## Структура

- `docs/` — продуктовые документы: PRD, глоссарий, гипотезы, бриф
- `ml/` — эксперименты с промптами и оценка качества
- `backend/`, `frontend/` — код сервиса

## Как запустить

```bash
docker compose up -d
```

Открыть http://localhost:3000
