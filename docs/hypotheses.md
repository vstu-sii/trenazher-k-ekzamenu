# Гипотезы

## Г1. Студент загрузит конспект

Мы считаем, что студент готов потратить пять минут на загрузку своего
конспекта, если взамен получит задачи по своему курсу.

**Как проверяем:** даём пятерым студентам ссылку, смотрим, сколько дошли
до загрузки.

**Опровергнута, если** меньше трёх из пяти дошли до загрузки: значит цена
входа выше ожидаемой пользы.

## Г2. Задачи по конспекту полезнее задачника

Мы считаем, что задачи, сгенерированные по конспекту, ближе к экзамену,
чем задачи из общего задачника.

**Как проверяем:** показываем преподавателю по десять задач из обоих
источников вперемешку, просим отметить те, что мог бы дать на экзамене.

**Опровергнута, если** преподаватель отметит задачи из задачника не реже,
чем наши.

## Г3. Разбор ошибки удерживает студента

Мы считаем, что объяснение ошибки со ссылкой на конспект заставит
студента решить следующую задачу, а не закрыть вкладку.

**Как проверяем:** считаем долю сессий, где после неверного ответа
студент взял ещё одну задачу.

**Опровергнута, если** эта доля ниже половины.
