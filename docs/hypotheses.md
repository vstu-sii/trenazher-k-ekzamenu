# Гипотезы

## Г1. Студент загрузит конспект

Мы считаем, что студент готов потратить пять минут на загрузку своего
конспекта, если взамен получит задачи по своему курсу.

Проверяем: даём пятерым студентам ссылку, смотрим, сколько дошли до
загрузки.

## Г2. Задачи по конспекту полезнее задачника

Мы считаем, что задачи, сгенерированные по конспекту, ближе к экзамену,
чем задачи из общего задачника.
