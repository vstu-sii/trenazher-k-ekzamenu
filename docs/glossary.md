# Глоссарий команды

Термины, которыми мы пользуемся в UC и в коде. Определения свои — так,
как понимаем внутри команды.

**Конспект** — файл с лекциями, который студент загружает. Не учебник и
не методичка: именно его записи, с его сокращениями и пропусками.

**Тема** — кусок конспекта, по которому можно задать задачу. Границы
темы определяем по заголовкам в конспекте, а если их нет — по смысловым
переходам.

**Задача** — сгенерированное задание с известным ответом. Отличается от
вопроса тем, что имеет однозначно проверяемый результат.

**Попытка** — один ответ студента на одну задачу. Попытки копятся:
третья подряд ошибка по теме означает, что тему надо объяснять заново, а
не давать новую задачу.

**Разбор** — объяснение, почему ответ неверный, со ссылкой на место в
конспекте. Не решение: решение мы не показываем, пока студент не сдался.

**Пробел** — тема, где доля верных ответов ниже половины. Из пробелов
строится план подготовки на оставшиеся дни.
